# 🐈‍⬛ Bóveda del Gato Negro — Link in Bio

> Página de enlaces (Link in Bio) para Instagram y redes sociales, diseñada con el estilo visual de la **Bóveda del Gato Negro**.

---

## 🌐 ¿Qué es esto?

Esta es una página web minimalista y responsive que funciona como un **"Link in Bio"** (o Linktree) para el perfil de Instagram de **@pablosnchz**.

Unifica en un solo lugar todos los enlaces importantes del proyecto y la comunidad:

- Redes sociales (Discord, Instagram, YouTube, Twitch, GitHub)
- El proyecto principal: **Bóveda del Gato Negro (GW2 WebApp)**
- Plataformas de apoyo (PayPal, Ko-fi)

---

## 🎨 Características

- ✅ **Diseño 100% idéntico al estilo de la Bóveda** (fondo oscuro, bordes sutiles, detalles dorados y azules).
- ✅ **Iconos oficiales** reutilizados desde el repositorio principal (`gw2-wallet-ligero`).
- ✅ **Mobile-first:** diseñado para verse perfecto en teléfonos celulares.
- ✅ **Sin dependencias externas:** no necesita JavaScript, ni librerías, ni imágenes externas (los iconos se cargan desde el repositorio principal).
- ✅ **Desplegado en GitHub Pages** de forma gratuita.

## 🛠️ Cómo usarlo en tu perfil de Instagram

1. Ve a tu perfil de Instagram.
2. Toca **Editar perfil** → **Enlaces** → **Agregar enlace externo**.
3. Pega la URL: `https://pablosnchz.github.io/bio/`
4. Ponle el título: `Bóveda del Gato Negro` (o el que prefieras).
5. Guarda los cambios.

¡Listo! Cualquier persona que visite tu perfil podrá acceder a toda tu comunidad y proyectos con un solo clic.

---

## 📦 Despliegue propio (para forks)

Si quieres usar este template para tu propio Link in Bio:

1. Haz un fork de este repositorio.
2. En **Settings > Pages**, activa GitHub Pages desde la rama `main` y la carpeta `/(root)`.
3. Edita el archivo `index.html` para cambiar los enlaces y el nombre.
4. Listo.
